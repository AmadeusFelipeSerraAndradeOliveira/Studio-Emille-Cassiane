AVISO DE PRIVACIDADE

Seus dados,
com cuidado.

Este aviso é um modelo e precisa ser revisado e completado pelo responsável pelo studio antes da publicação. Ele não substitui uma análise jurídica.

Quais dados são solicitados

O formulário solicita nome, telefone/WhatsApp, serviço, data, horário e, se necessário, uma observação. Não inclua dados sensíveis no campo de observação.

Para que usamos os dados

Os dados são usados para receber, avaliar e responder ao pedido de agendamento, além de organizar os atendimentos. O studio pode contatar você pelo telefone informado para confirmar ou esclarecer o pedido.

Onde ficam armazenados

Os pedidos são armazenados no Cloud Firestore do projeto Firebase escolhido pelo studio e ficam visíveis apenas a administradores autorizados. O link do WhatsApp abre o aplicativo de mensagens com um texto preenchido; você decide se deseja enviá-lo.

Retenção e seus direitos

O studio deve definir o prazo de retenção adequado, considerar obrigações legais e atender solicitações de acesso, correção ou exclusão quando aplicável. A rotina opcional do painel apaga apenas pedidos recusados, expirados ou cancelados com mais de 60 dias, após exportação e confirmação administrativa; não é uma tarefa automática em horário fixo.
